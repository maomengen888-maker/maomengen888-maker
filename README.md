## 🛠️ 我的工作方式

- **从用户问题开始：** 先厘清场景、约束和证据，再讨论功能与模型。
- **把假设说清楚：** 区分事实、判断、建议和待确认项，减少过早确定方案。
- **设计完整 Agent：** 明确输入输出、人机分工、工具调用、上下文和失败兜底。
- **亲手验证体验：** 用原型和可运行产品验证交互，不让 PRD 停在文档里。
- **让质量可衡量：** 定义正常/异常用例、验收标准、观测信号和迭代闭环。

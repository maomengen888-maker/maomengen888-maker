## How I approach AI products

- Start with the user problem, scenario, constraints, and evidence.
- Separate facts, assumptions, recommendations, and open questions.
- Define model input/output, human–AI collaboration, and failure fallback.
- Treat quality as measurable: evaluation criteria, edge cases, signals, and iteration loops.

> Good AI products do not merely make a model look smart. They help users complete a real task reliably, controllably, and measurably.
